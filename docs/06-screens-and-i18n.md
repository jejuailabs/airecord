# 06 — 화면 구조 & 다국어

> 선행 문서: `core.md`, `docs/05-design-system.md`

## 1. 라우트 트리

```
/[locale]
├── (marketing)
│   ├── /                     랜딩
│   ├── /pricing              요금제
│   └── /login                Google 로그인 버튼 하나
│
├── (app)                     ← 인증 필요. 미들웨어 가드
│   ├── /dashboard            홈. 시작 화면 겸용
│   ├── /live                 모드 B 통역 화면
│   ├── /meeting              모드 A 시작
│   │   └── /meeting/[id]     진행 중 회의 모니터
│   ├── /sessions             기록 목록
│   │   └── /sessions/[id]    기록 상세 (원문·번역 대조)
│   └── /settings
│       ├── /settings/workspace   이름, 보관 정책, 오디오 저장 여부
│       ├── /settings/members     초대·역할
│       ├── /settings/usage       사용량·잔여 분
│       └── /settings/billing     플랜·결제
│
└── (없음)
/v/[token]                    자막 뷰어 — 인증 불필요, locale 세그먼트 밖
```

`/v/[token]`을 `[locale]` 밖에 두는 이유: 회의 채팅에 뿌려지는 링크는 짧고 언어중립적이어야 한다. 뷰어 UI 언어는 브라우저 `Accept-Language`로 판단한다.

## 2. 화면별 스펙

### 2.1 `/dashboard` — 홈
이 화면의 유일한 목적은 **3초 안에 통역을 시작시키는 것**이다.

```
┌────────────────────────────────────────────────────────────┐
│  통역 시작                                                   │
│                                                            │
│  ┌────────────────────────┐  ┌────────────────────────┐    │
│  │  🎙  대면 통역           │  │  🔗  화상회의 통역       │    │
│  │  마이크로 바로 시작       │  │  회의 주소 붙여넣기       │    │
│  │                        │  │  ┌──────────────────┐  │    │
│  │  한국어 ⇄ English  ▾    │  │  │ 회의 링크 붙여넣기 │  │    │
│  │  [  시작  ]             │  │  └──────────────────┘  │    │
│  └────────────────────────┘  └────────────────────────┘    │
│                                                            │
│  이번 달 남은 시간  ▓▓▓▓▓▓▓░░░  218분 / 300분              │
│                                                            │
│  최근 기록                                        전체 보기 →│
│  ─────────────────────────────────────────────────────    │
│  ● 라이브   제품 리뷰 미팅        한→영    진행 중  12:04    │
│    7월 24일  공급사 통화          한→일    24분             │
└────────────────────────────────────────────────────────────┘
```

**규칙**
- 언어쌍은 마지막에 쓴 값이 미리 채워져 있다(`User.defaultSourceLang/TargetLang`). 매번 고르게 하지 않는다.
- 회의 링크 입력칸은 **붙여넣는 즉시** 플랫폼을 판별해 아이콘을 띄우고, 유효하면 버튼이 활성화된다. "다음" 단계가 없다.
- 잔여 시간 바는 20% 미만이면 `--warn`, 0이면 `--danger`로 바뀌고 업그레이드 링크가 붙는다.

### 2.2 `/live` — 모드 B 통역 화면
- 시작 전: 마이크 권한 요청 → 입력 레벨 미터(소리가 들어오는지 확인) → 언어쌍 → 큰 시작 버튼.
- 진행 중: 화면의 대부분이 자막 패널(`docs/05 §4`). 상단에 경과 시간·언어쌍·라이브 점, 하단에 종료 버튼 하나와 음성 출력 토글.
- **화면에 보이는 컨트롤은 4개를 넘지 않는다:** 종료 / 음성 출력 / 자막 크기 / 전체화면.
- 종료 시 확인 다이얼로그를 띄우되, "기록이 저장됩니다"를 함께 알린다.

### 2.3 `/meeting/[id]` — 모드 A 모니터
- 봇 상태를 단계로 보여준다: `입장 중 → 대기실 → 통역 중 → 종료`. 각 단계에서 무슨 일이 일어나는지 한 줄씩.
- 자막 링크를 크게 노출 + 복사 버튼(채팅 게시가 실패했을 경우의 안전망).
- 자막 미리보기 패널.
- 종료 버튼 = 봇 퇴장.

### 2.4 `/v/[token]` — 자막 뷰어 (공개)
- **로그인 유도 없음.** 상단에 작은 제품 로고만.
- 첫 진입 시 하단에 고지 배너 1회 노출: "이 대화는 통역을 위해 기록됩니다." (닫기 가능. `docs/08 §2`)
- 자막 크기 조절 · 전체화면 · 원문 표시 on/off.
- 세션 종료 후에는 전체 스크립트를 스크롤로 읽을 수 있고, 보관 기간이 지나면 만료 안내를 보여준다.

### 2.5 `/sessions/[id]` — 기록 상세
- 좌: 타임 레일 + 세그먼트 목록(원문·번역 대조). 우: 메타(시간, 언어, 분, 참여자).
- 검색: 원문·번역 양쪽에서 텍스트 검색, 매치 하이라이트.
- 내보내기: **TXT · Markdown · PDF**. 오디오는 저장 설정이 켜진 경우에만.
- 삭제 버튼(역할에 따라).

### 2.6 `/settings/usage`
- 이번 주기 사용 분 / 포함 분 / 초과 분.
- 일별 막대그래프(모드별 색 구분).
- 멤버별 사용량 표(관리자만).
- **원가·마진은 유저에게 보여주지 않는다.** 내부 지표다.

## 3. 화면 전반 규칙

- **모달은 파괴적 행동에만.** 나머지는 인라인 또는 사이드 패널.
- **확인 문구는 결과를 말한다.** "삭제하시겠습니까?" 대신 "이 세션의 자막과 오디오를 삭제합니다. 되돌릴 수 없습니다."
- **버튼 이름이 흐름 전체에서 같다.** "시작"으로 시작했으면 토스트도 "통역을 시작했습니다".
- **로딩 중에도 다음 행동을 막지 않는다.** 봇 입장을 기다리는 동안 다른 페이지로 이동할 수 있어야 한다.

## 4. 다국어 (next-intl)

### 4.1 가장 중요한 구분

> **UI 언어(`uiLocale`)와 통역 언어(`sourceLang`/`targetLang`)는 완전히 다른 개념이다.**
> 한국인이 한국어 UI로 영↔일 통역을 돌릴 수 있다. 이 둘을 한 설정으로 묶으면 제품이 망가진다.
> 코드에서 절대 같은 변수·같은 컴포넌트를 공유하지 않는다.

| | UI 언어 | 통역 언어 |
|---|---|---|
| 타입 | `UiLocale = 'ko' \| 'en' \| 'ja' \| 'zh-CN'` | `LangCode` (엔진 지원 목록) |
| 저장 | `users/{uid}.uiLocale` + 쿠키 | `sessions/{id}.sourceLang/targetLang` |
| 바꾸는 곳 | 계정 메뉴 | 세션 시작 화면 |
| 개수 | 4개 (초기) | 수십 개 |

### 4.2 설정
```
지원 로케일   ko(기본) · en · ja · zh-CN
경로 방식     /[locale]/... , 기본 로케일도 접두사 표기 (as-needed 아님 — 링크 공유 시 혼란 방지)
판정 순서     쿠키 NEXT_LOCALE → 로그인 유저의 uiLocale → Accept-Language → ko
메시지 파일   apps/web/src/messages/{ko,en,ja,zh-CN}.json
```

### 4.3 메시지 키 규칙
```jsonc
{
  "dashboard": {
    "startInPerson": { "title": "대면 통역", "subtitle": "마이크로 바로 시작" },
    "remaining": "이번 달 남은 시간 {used}분 / {total}분"
  },
  "session": {
    "status": { "live": "통역 중", "ended": "종료됨", "failed": "실패" },
    "segments": "{count, plural, =0 {자막 없음} other {자막 #개}}"
  },
  "errors": {
    "insufficientMinutes": { "title": "남은 시간이 부족합니다", "action": "요금제 보기" },
    "botJoinFailed": { "waitingRoom": "호스트가 봇을 승인하면 통역이 시작됩니다." }
  }
}
```
- 키는 **화면·기능 기준**으로 중첩한다. 알파벳순 평면 구조 금지.
- 복수형은 ICU plural로. 문자열 이어붙이기 금지.
- 오류 메시지는 `title` + `action`을 항상 쌍으로 가진다(`core.md §6`).

### 4.4 지켜야 할 것
- **하드코딩 문자열 0개.** ESLint 규칙(`no-literal-string` 계열)으로 CI에서 막는다.
- 날짜·시간·숫자는 `next-intl`의 포매터를 쓴다. 직접 `toLocaleString` 호출 금지.
- 언어 이름은 자기 언어로 표기한다: `한국어 / English / 日本語 / 中文(简体)`.
- 번역 누락 시 `ko`로 폴백하고, 개발 모드에서는 콘솔 경고를 띄운다.
- 일본어·중국어는 같은 폰트 스택에서 글리프가 다르게 잡힐 수 있으므로 해당 로케일에서 폰트 스택을 확인한다.
- 텍스트 확장 대비: 독일어 등 확장 언어를 나중에 추가할 수 있게 **버튼 폭을 텍스트에 딱 맞추지 않는다**(최소 폭 + 패딩).

### 4.5 초기 번역 범위
Phase 1~3은 **`ko` + `en`만** 완성한다. `ja` / `zh-CN`은 파일 구조만 만들어 두고 Phase 5에서 채운다. 미완성 로케일은 언어 선택 목록에 노출하지 않는다.
